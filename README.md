## Summary of findings

The five supplied paired transcripts indicate that participants generally found the redesigned interface easier to explore than the original Angel One website. The clearest themes were simpler navigation, a more approachable learning section, quicker access to the SIP calculator, and improved text-size and contrast controls. Participants also identified issues that remain: unfamiliar financial terms, unclear SIP return assumptions, accessibility options that need better descriptions, and form/keyboard-focus details.

These are qualitative findings from the supplied comment texts. They should not be treated as proof of faster task completion, lower error rates, or formal accessibility compliance.

## Study limitations

The text files are treated as supplied paired comments and have not been independently verified against the audio recordings. The participant mapping in the filenames and transcript headings is preserved as supplied. The study uses five participants, so the findings are exploratory and should not be generalized to all investment-platform users. The Figma Make prototype is the stated prototype reference; this report does not claim that every production website function or accessibility requirement has been verified.

## Main recommendations

1. Explain financial terms such as NAV, expense ratio, and risk level using plain language and optional information hints.
2. Make SIP assumptions explicit and show invested amount separately from estimated returns.
3. Make the accessibility control easy to notice and explain what Reading Comfort and Reduced Motion change.
4. Use persistent form labels, clearer account-opening progress, and more visible keyboard focus.
5. Test the prototype with a broader set of users, including people with visual accessibility needs, and record task success, errors, and completion time if quantitative evaluation is required.
